Glass Feedback

A demo page with light, dark, and photographic regions so the glass UI can be judged over unpredictable backgrounds.

Light region

Frosted glass should stay legible here. Try the select tool to crop, and the type tool to drop a note.

Notes are solid + eye-friendly (dark or light), per spec — not glass — so the text you write stays crisp.

Dark region

The pill is edge-pinned and draggable. Tap it to expand into the tool row. The toolbar carries the full glass treatment (sheen, rim, grain, subtle refraction).
