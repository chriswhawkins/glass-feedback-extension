Glass Feedback couldn't open

Chrome blocks tools on browser settings, the Chrome Web Store, other extensions, and some built-in viewers or error pages. On a regular website, a loading or connection error can also prevent the tools from opening.

Open a regular website and click Glass Feedback again. Access is temporary and granted by your click; it does not request access to all websites.

If Chrome has blocked site access, review Glass Feedback's permissions in the Extensions menu. For local files, enable “Allow access to file URLs” in the extension's details.

If this is a regular website, reload the page and try again. After an extension update, reload the extension and the page.
